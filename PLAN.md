# План: новый веб-фронт для dcm4chee-arc-light

Отметки проставляются по факту выполнения. Отклонения от плана и найденные грабли
фиксируются здесь же, в разделе «Журнал».

**Статус:** фазы 0–1 готовы, фаза 2 в работе.

---

## Зачем

Штатный UI архива (`dcm4chee-arc-ui2`, Angular) перегружен: глубокая вложенность экранов,
нет нормального поиска, неочевидная навигация. Весь функционал архива при этом доступен
через REST — Angular-UI просто клиент к тем же эндпоинтам. Пишем своё SPA рядом, бэкенд
не трогаем: старый UI остаётся как fallback, апгрейды архива ничего не ломают.

## Целевой UX

1. **Омнибокс вместо форм.** Одна строка: `Иванов`, `20240513`, `CT`, `acc:12345`,
   `1.2.840.113619...` → QIDO-параметры. Явные префиксы: `pid:` `acc:` `mod:` `date:` `desc:` `aet:`.
2. **Плоский список** исследований, а не дерево patient → study → series → instance.
   Пресеты дат, мультиселект модальностей — чипами. Состояние фильтров в URL.
3. **Детали — в боковой панели**, без ухода со списка.
4. **Клавиатура:** `/` поиск, `j/k` навигация, `Enter` детали, `v` вьюер, `?` помощь.
5. **Задачи одним списком** (export/retrieve/stgver/diff) с общими фильтрами и bulk-действиями.
6. **Конфиг — только практичное**, в режиме чтения.

## Стек

React 19 + TypeScript + Vite 8 · TanStack Router / Query / Table · Tailwind v4 ·
cornerstone3D 5.x · dcmjs. API-клиент — тонкий рукописный типизированный слой
на ~25 нужных эндпоинтов (`docs/openapi.json` — справочник, codegen не берём:
внешние `$ref` + 285 путей шума).

## Риски

| Риск | Митигация |
|---|---|
| QIDO тормозит на большой базе | всегда `limit`+`offset`, `includefield` только нужное, счётчик отдельным запросом |
| Нечёткий поиск по ФИО не включён на сервере | `fuzzymatching=true` + wildcard; в доке — как включить `dcmFuzzyAlgorithmClass` |
| Сжатые transfer syntax во вьюере | декодеры cornerstone3D, fallback на серверный `/rendered` |
| Разница версий 5.35 (стенд) vs рабочий сервер | опираемся на стабильные QIDO/WADO/STOW, отличия проверяем при подключении |
| Права доступа на secure-инстансе | UI скрывает действия по ролям, сервер — источник истины |
